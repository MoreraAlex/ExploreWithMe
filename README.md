# java-explore-with-me
Template repository for ExploreWithMe project.

Дополнительная функциональность: подборки событий по интересам

Описание:
Пользователь сможет указать интересующие категории, а основной сервис будет формировать персональную подборку
событий на основе этих предпочтений и популярности событий.
